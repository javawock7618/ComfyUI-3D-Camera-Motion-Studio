# ComfyUI-3D-Camera-Motion-Studio

ComfyUI 向けの軽量でカメラモーション作成に特化した 3D シーン＆キーフレームスタジオ・カスタムノードです。`MiniMax-H3 Ref2VA ControlNet` などの映像生成ワークフローにおけるプリビズ作成やカメラパス出力をスムーズに行えるよう設計しています。

## コンセプト

* **シンプル＆軽い**: Three.js ベースの軽量なビューポートで、複雑な 3D 機能に振り回されずサクサク編集できます。
* **キーフレーム複数対応**: 複数キーフレームによるカメラワーク、区間ごとのイージング、FOV（画角）変化、オブジェクト移動を組み合わせられます。
* **カメラモーション作成に特化**: アングル決めやカメラ軌跡の作成、連番画像（`IMAGE`）出力にフォーカスした実用重視のUIです。

## 主な機能

* **3Dビューポート・モデル／シェイプ操作**:
  * `.glb` モデルの読み込みとアニメーションクリップ選択・フレーム同期再生（`GLB Motion` / `Sync`）。
  * 基本シェイプ（`Box` / `Sphere` / `Cylinder` / `Plane` / `Cone`）のワンクリック追加。
  * RGB ギズモ（`Move (XYZ)` / `Rotate`）、数値入力・ラベルドラッグ操作（`Position` / `Rotation` / `Scale`）、`Reset` に対応。
* **キーフレーム・編集テンポ向上**:
  * キーフレームの追加（`◆ Add KF`）、上書き更新（`✎ Upd`）、削除（`✕ Del`）、リセット（`↺ Reset`）、前後ジャンプ（`◀` / `▶`）。
  * タイムライン上のキーフレームマーカー（◆）の左右ドラッグ移動（他キーフレームとの重複自動回避・リアルタイム追従）。
  * キーフレーム区間ごとの個別イージング（`Linear` / `Ease In` / `Ease Out` / `Ease In-Out`）、カメラ `FOV`（`30°`〜`75°`）、注視点スナップ（`◎ Tgt`）。
  * アンドゥ／リドゥ（`↶` / `↷`、ショートカット `Ctrl+Z` / `Ctrl+Y`・`Ctrl+Shift+Z`）。
  * カメラだけでなくオブジェクトの位置・回転・スケールもキーフレーム記録＆補間移動に対応。`Path` ガイド表示の切り替えも可能。
* **出力・プリセット管理**:
  * 書き出し時の見た目切り替え（`Out`: `Standard` / `Wireframe` / `Depth` / `Normal`）と `Grid` 表示切り替え。
  * シーン・モデル状態・キーフレームの JSON 保存／読み込み（`Save JSON` / `Load JSON`）。
  * ComfyUI Nodes 1.0 / 2.0 両対応のレイアウトとウィンドウサイズ維持。

## インストール方法

1. `ComfyUI/custom_nodes/ComfyUI-3D-Camera-Motion-Studio` に本リポジトリを配置します。
2. 必要に応じて依存パッケージを確認します（`numpy` と `Pillow` は ComfyUI 標準環境に含まれます）。
3. ComfyUI を再起動し、ブラウザをスーパーリロード（`Ctrl+F5` / `Cmd+Shift+R`）してください。
